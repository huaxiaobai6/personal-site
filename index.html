独立设计 & 开发

NovelGraph

2026.05 — 至今

基于知识图谱的多 Agent 协作长篇小说生成系统。将"生成故事"拆解为演绎层（世界如何运转）与写作层（故事如何讲述）两个独立问题，解决传统 AI 写作中角色一致性低、情节不可控、长文质量衰减等核心问题。当前处于系统性重构阶段。

Python LangChain 知识图谱 多 Agent 架构 Docker
  • 知识图谱世界观 — 定义 5 类节点（角色/场景/移动/事件/指令）与有向关系边作为事实表示，所有状态变更通过图谱 diff 记录，全历史可追溯
  • 角色 Agent 自主决策 — 以图谱节点为单位独立行动，每轮产出三元输出（内心独白 + 外在行为 + 对话），私密不暴露，行为与语言公开合并
  • 导演 Agent 调度世界 — 负责场景激活/暂停、角色移动编排、巧合安排（NPC/环境）、跨场景事件传递，操作生效于下一个心跳；调度世界而非控制角色
  • 回合制并发架构 — 每轮所有 Agent 并行读取当前世界状态快照 → 各自独立决策并产出行为 → 统一合并写入知识图谱，叙事从行为中自然涌现
  • 冲突仲裁机制 — 有向关系更新和事件追加天然无冲突（各写各的边/append 操作），仅同一字段被多 Agent 同时修改时触发仲裁（后到覆盖，场景内 Agent 优先）
  • 双写手流水线 — 剧本写手读取原始世界记录 → 扫描关键事件 → 规划 POV/节奏/结构 → 生成章节；NG 否决机制仅回退导演操作和节奏编排，不否决角色的自主行为选择
  • 完整记录 vs 叙事取舍 — 系统保证世界完整性（所有事件被记录），写手决定哪些呈现给读者、哪些隐藏，增加叙事层次感
